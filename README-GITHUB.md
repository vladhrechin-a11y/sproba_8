## Що змінилося у V20
- Додано кнопку «← На головний екран» у розділі «Корисна інформація».
- У тестуванні залишено «Законодавство» та додано «Історія України».
- «Історія України» містить 100 питань; у кожній спробі випадково обираються 5.
- Усі питання законодавства мають рівно 5 варіантів відповіді.
- Варіанти, що починаються з «вірно/вірна/вірні» або «всі відповіді», автоматично ставляться останніми.
- У «Корисній інформації» приховано службові заголовки «Навчальний інформаційний ресурс», «Оберіть напрям», «Оберіть категорію навчальних матеріалів».
- Пошук залишається тільки у «Корисній інформації».

## V24 additions
- 🌦️ Weather tool added under Useful Tools.
- Uses Open-Meteo forecast and geocoding APIs.
- Supports current location or manual city search.
- Shows current conditions, hourly forecast, 7-day forecast, wind, gusts, precipitation, humidity, visibility, pressure, UV, sunrise/sunset, alerts and simple field conditions.
- Last successful forecast is cached locally for offline viewing.
